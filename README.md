# Сайт-резюме Артёма Некрасова, юрист

Одностраничный сайт без сборки и зависимостей: HTML, CSS и один скрипт.

## Как посмотреть

Откройте `index.html` двойным кликом. Шрифты подгружаются из Google Fonts, без интернета включатся системные.

Адрес `index.html?still` показывает страницу без анимаций, это удобно для снимков экрана.

## Палитра

Цвета сняты с референса (светлая презентация с синими заголовками и чёрными слайдами). Задаются в начале `css/base.css`; имена переменных исторические (`--lime` сейчас синий, `--milk` бумага):

| Переменная | Цвет | Где используется |
|---|---|---|
| `--hero`, `--milk` | `#f7f7f5` бумага | обложка и светлые секции, карточки |
| `--ink` | `#050506` чёрный | тёмные секции, текст на светлом |
| `--cream` | `#ffffff` белый | листы внутри карточек и рамка фото |
| `--lime`, `--lime-ink`, `--red` | `#2e4485` синий | фамилия на обложке, кнопки, выделения, акцентный текст на светлом, штамп, пометки от руки |
| `--lime-2` | `#3f5cb8` синий светлее | кнопки на чёрном, наведение |
| `--lime-soft` | `#7f9bf0` светлый тон синего | акцентный текст на чёрном: на нём основной синий не читается |
| `--on-lime` | `#ffffff` | текст на синей заливке |

Акцентный текст берёт цвет из `--lime-text`: на светлых секциях это `--lime-ink`, на чёрных `--lime-soft` (переключается по `data-theme` секции, см. конец `css/sections.css`).

## Где что лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Вся разметка и тексты: обложка, цифры, образование, два места работы, «Право в теории / на практике», навыки, контакты |
| `css/base.css` | Цвета, шрифты, кнопки, навигация |
| `css/sections.css` | Все секции, кроме опыта |
| `css/cases.css` | Два места работы и переключатель между ними |
| `js/app.js` | Вступление, счётчики, меню, переключение карточек |
| `assets/img/` | Портрет на обложке (прозрачный фон), фото с дипломом (кадр 4:5), картинка превью ссылки `og.jpg` |

Тексты взяты из резюме на hh. Ситуации в разделе «Право в теории / на практике» условные, это подписано на странице.

## Публикация

Адрес сайта: https://nekrasov-law.github.io/ (GitHub Pages, репозиторий `nekrasov-law/nekrasov-law.github.io`, ветка `main`).

Чтобы обновить сайт после правок:

```bash
git add -A && git commit -m "Что изменилось" && git push origin main
```

Через минуту-две изменения появятся по адресу. В начале `index.html` адрес картинки превью (`og:image`) записан полностью; при переезде на другой адрес его нужно поменять.
